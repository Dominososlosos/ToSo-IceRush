# ICE RUSH Architecture

This document defines the initial architecture for the ICE RUSH datapack.

## Planned modules
- Core engine
- Config
- Arena generation
- Lobby
- Join/Ready
- Game state machine
- Countdown
- Race engine
- Speed engine
- Turbo
- Cracks
- Random events
- Parking
- Elimination
- Winner
- Statistics
- Achievements
- Admin

The project will be implemented module-by-module with performance as a primary goal.
